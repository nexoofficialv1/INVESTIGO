# INVESTIGO internal checkpoint v1.7.3

This checkpoint adds independent Final CD, Charge Sheet and IF-5 review workflows on the Regular Case domain.

## Included
- Separate editor/review screen for each document.
- Separate local draft persistence and IO approval.
- Regular Case auto-fill from daily CD, witness statements, accused and sections.
- PDF and DOC preview/export.
- Closure readiness warnings.
- Required documentation updates and model tests.

## Not yet a final release
Physical line/column calibration against printed official blank forms and full Flutter/Android build validation are still required before RC-1.
