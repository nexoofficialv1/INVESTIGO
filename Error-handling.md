# INVESTIGO Error Handling

## General rules
- Never silently discard officer-entered data.
- Keep drafts when preview/export fails.
- Show a concise Bengali/English message and a retry action.
- Record technical details without sensitive record contents.

## Document generation
- Generate bytes once and reuse them for preview/share.
- Long CD content must be split into page-safe rows.
- A template overflow must show an error instead of an endless spinner.
- Preview timeout: 45 seconds with Retry.
- Missing required fields produce validation warnings; they do not alter the locked layout.

## Storage
- Old JSON remains readable through defaults.
- A malformed record is skipped with a visible warning; valid records continue loading.
- Domain stores reject calls with the wrong domain type.

## Narration
- If no action is detected, preserve the narration and ask the officer to create a manual entry.
- A normally-once action repeated without justification is not saved.
- Witness statements remain repeatable.

## Export
- If DOC writing or sharing fails, retain the generated bytes and offer retry.
- File names must remove path separators and unsafe characters.

## Sketch map compatibility
Unknown legacy object types fall back to `house` without crashing. Rotation and size values are preserved through JSON round trips.

## Closure-document validation

Before Final CD/CS/IF-5 approval, the app must report missing case number,
sections, daily CD, witness list, accused status or investigation summary.
Validation errors must keep the draft editable; they must never discard saved
case data or silently fabricate missing facts.

## Final-document safeguards
- Missing required fields block approval but do not destroy the draft.
- Preview first saves the current draft.
- Stored drafts are scoped by case ID and document type.
- A missing saved draft falls back to a newly generated editable draft from Regular Case data.

## Legacy draft compatibility
New final-document fields use defaults when opening older locally saved drafts. Approval remains blocked when required core fields are missing.
